# 领域文档

采用单上下文布局：

- 根目录 `GLOSSARY.md`：领域术语。
- 根目录 `docs/adr/`：架构决策。

## 阅读规则

探索代码前，读取已有术语表，以及涉及当前修改区域的 ADR。
文件不存在时直接继续，不预建空文件，也不因缺失而暂停。

任务标题、设计说明和测试名称使用术语表中的既定用词。
发现术语缺口时，留待相关领域建模工作处理。

若拟议修改与已有 ADR 冲突，指出冲突及理由，
不静默覆盖已有决定。
