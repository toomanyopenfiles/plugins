# 分诊标签

| skill 角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格完整，可开始实施 |
| ready-for-human | ready-for-human | 需要人工操作 |
| wontfix | wontfix | 不予实施 |

skill 提及角色时，使用对应 GitHub 标签。

标签不扩大任务授权。`ready-for-agent` 仅表示规格完整。
用户已允许所选 spec 实施编排流程使用其必要的模型调用和实施子代理；
这不授权通过真实模型或被测代理验证 pstack → Pi 适配效果。
标签不能替代用户授权或跳过批准边界。

此文件记录标签映射；使用前以远端实际标签为准。
